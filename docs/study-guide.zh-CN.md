# CS61A 学习指南

这份指南适合配合本仓库里的 starter code、官方公开 guide 和你自己的练习记录一起使用。默认不直接给答案，完整参考答案放在 `private/answers/`。

## 使用方式

1. 每完成一个 lab / hw / project，就回到这份指南做一次自测。
2. 不会的题先回看对应代码、注释、官方页面，再看私有答案。
3. 每一题尽量先口述思路，再动手写代码。

## 模块一：Python 与求值

1. 解释表达式求值、函数调用、返回值之间的关系。
2. `print` 和 `return` 的差别是什么？
3. 什么叫纯函数？为什么纯函数更容易测试？
4. 递归函数至少要满足哪两个条件？

## 模块二：高阶函数与环境模型

1. 什么是高阶函数？请给出一个接收函数和一个返回函数的例子。
2. 闭包为什么能保存外层变量？
3. 什么时候应该画环境图？
4. 用自己的话解释 lexical scope。

## 模块三：递归、树递归与数据抽象

1. 普通递归和树递归的主要区别是什么？
2. 为什么抽象屏障对大型程序很重要？
3. list、tree、linked list 在思维方式上有什么不同？
4. 什么时候应该先写构造器和选择器？

## 模块四：可变状态与对象

1. 可变状态为什么会增加调试难度？
2. 类属性和实例属性的差别是什么？
3. 组合与继承分别适合解决什么问题？
4. 写一个类时，什么情况下应该实现 `__repr__`？

## 模块五：Scheme 与解释器

1. Scheme 的求值和 Python 最重要的差异是什么？
2. 什么是 special form？
3. 解释器至少需要处理哪几类对象？
4. 为什么说“写解释器”会反过来加深你对语言本身的理解？

## 模块六：SQL 与综合复习

1. `SELECT`、`FROM`、`WHERE`、`GROUP BY` 分别在做什么？
2. 声明式语言与命令式语言的核心差异是什么？
3. 如果考试前只剩两天，你会如何安排复习优先级？
4. 如何判断自己是真的“理解了”，而不是只看懂了解答？

## 练习复盘模板

每做完一题，至少补这四项：

- 我原本的思路是什么？
- 卡住的具体点是什么？
- 正确思路的关键转折是什么？
- 下次遇到同类题，我先检查哪三个信号？
