# CS61A 学习路线图

本仓库围绕 Berkeley 官方公开的 CS61A 课程资料整理，目标不是替代原课，而是帮助你用更顺手的结构在本地持续学习、练习和复盘。

## 课程核心主线

1. Python 基础与程序抽象
2. 高阶函数、环境模型与递归
3. 树、链表、生成器与数据抽象
4. 面向对象、可变状态与效率
5. Scheme、解释器与语言设计
6. SQL、数据处理与综合项目

## 推荐学习顺序

### 第一阶段：起步与 Python 基础

- 先做 `lab00`，把本地环境、命令行、Python 运行方式和课程工作流跑通。
- 继续完成前几次 `lab` 与 `hw`，重点掌握：
  - 表达式求值
  - 函数定义与调用
  - 控制流
  - 递归基础

### 第二阶段：抽象能力建立

- 集中突破高阶函数、树递归、数据抽象。
- 学习时建议反复画环境图，弄清楚：
  - 变量绑定在哪里产生
  - 闭包为什么能“记住”环境
  - 递归和迭代过程的差别

### 第三阶段：项目驱动理解

- 项目通常比单次作业更能暴露理解缺口。
- 推荐按课程节奏推进公开项目：
  - `hog`
  - `cats`
  - `ants`
  - `scheme`
  - `scheme_contest`
  - `scheme_gallery`

### 第四阶段：语言与解释器

- 这一段是 CS61A 很有代表性的部分。
- 要重点理解：
  - Scheme 的求值规则
  - 解释器如何表示环境
  - 特殊形式与普通函数调用的区别

### 第五阶段：冲刺复习

- 使用 `materials/guides/` 中同步下来的复习资料：
  - Studying Guide
  - Composition Guide
  - MT1 / MT2 / Final Study Guide
- 建议把错题、易混概念和模板化解题步骤补充到 `private/answers/` 中，形成自己的闭卷复习材料。

## 每周学习节奏建议

1. 先看 lecture / textbook 对应章节，建立概念。
2. 再做 lab，快速验证基本操作。
3. 接着做 homework，强化思维细节。
4. 项目周预留更完整的连续时间块。
5. 每周至少做一次总结，回答“本周最容易错在哪里”。

## 本仓库使用建议

- `docs/`：公开的中文学习资料与导读
- `materials/`：从官方站点同步下来的原始资料与 starter code
- `private/answers/`：你的完整答案、错题总结、项目思路和私有笔记

## 学习原则

- 先自己推理，再看答案。
- 先理解环境模型，再背结论。
- 先跑最小样例，再扩展到完整题目。
- 先复盘“为什么错”，再追求“做完更多题”。
