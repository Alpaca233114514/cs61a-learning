# Pytea · 本地 Python 导师

Pytea 是本仓库中的 Python 执行可视化工具，布局参考 Python Tutor：左侧代码与步进控制，右侧调用帧和对象引用图。它使用本机 CPython 记录真实执行快照，不调用 AI 服务，也不需要第三方包或联网资源。

## 启动

要求 Python 3.10 或更新版本。已在 Windows / Python 3.13 上验证。

```powershell
python scripts/install_pytea.py
pytea
```

Windows 安装器在当前 Python 的 `Scripts` 目录中创建 `pytea.cmd`。该目录需要位于 PATH 中；安装器会检查并提示，不擅自修改 PATH。启动脚本绑定当前仓库路径和 Python 解释器；移动仓库后重新执行安装器。安装器拒绝覆盖不属于它的现有命令。

不安装命令也可在仓库根目录执行 `python -m pytea`。macOS / Linux 安装器会写入 `~/.local/bin/pytea`，这两个平台尚未实机验证。

启动后自动打开默认浏览器；终端保持运行，按 `Ctrl+C` 关闭服务。默认自动分配空闲端口，可指定：

```powershell
pytea --port 8765
pytea --no-browser
```

手动打开时，复制终端显示的完整地址，包括 `#token=...`。不要分享该地址，它包含当前本地服务的运行凭证。

## 使用

1. 输入代码，或选择内置示例：函数绑定、递归、闭包、共享列表、类与实例、循环与输入。
2. 若代码使用 `input()`，展开「输入数据」，按调用顺序每次提供一行。
3. 点击「可视化执行」，或按 `Ctrl+Enter` / `⌘+Enter`。
4. 使用首步、上一步、下一步、末步、进度条或自动播放回看。焦点不在输入控件时，可用左右方向键步进。
5. 点击「编辑代码」返回编辑状态。右上角可切换简体中文和 English。

红色行是即将执行的位置，此时右侧显示执行该行**之前**的状态；绿色行是最近一次执行的位置。返回事件会显示返回值。输出随回放步骤变化。回退只是查看保存的快照，不会撤销文件写入等代码副作用；再次点击「可视化执行」则会重新执行代码。

简单值直接显示；函数、容器和实例以对象卡片呈现。多个变量指向同一个对象时会使用相同编号和引用箭头。列表循环引用也保留对象身份。闭包卡片显示捕获变量。

## 范围与限制

- 每次最多 600 个跟踪事件，执行子进程最多运行 5 秒；输出上限 20,000 字符，返回轨迹上限 30 MB。
- 为控制图的大小，单个容器最多显示 50 项，每层绑定最多检查 150 项，每步最多展开 100 个对象，递归展开深度最多 8 层。容器标题中的长度是真实总长度；超出展开范围的对象会显示省略提示。
- 按 Python 行事件跟踪，不拆分同一行中的每个子表达式。导入模块内部的执行不展开。只显示当前活动调用帧与可达对象，不完整模拟课程手绘环境图中的词法父帧；返回后的闭包显示捕获值。
- 面向单线程同步教学代码。生成器、协程、多线程、原生扩展内部和自定义元类行为不保证准确呈现；实例主要显示 `__dict__` 属性，不展开 `__slots__`。
- 普通 `print()` / Python 标准输出会被记录；直接写操作系统输出句柄的扩展不在捕获范围内。
- 编辑内容只存在页面中，刷新会回到默认示例。重要代码请另外保存在文件里。

## 本地执行边界

**仅运行自己编写或信任的代码。此工具不是安全沙箱。** 代码具有启动用户的本地文件、网络和系统权限。子进程超时不是操作系统资源隔离，也不能保证停止用户代码自行启动的其他进程。

服务仅绑定 `127.0.0.1`，运行接口检查 Host、同源 Origin 和随机启动凭证，并且每个服务同时只允许一个执行请求。页面不加载远程脚本，不发送代码给外部服务。轨迹通过临时文件在子进程与服务之间传递，正常结束后自动清理。

## 开发验证

```powershell
python -m unittest discover -s tests -v
node --check pytea/static/app.js
```

Node 只用于可选 JavaScript 语法检查，运行 Pytea 不需要 Node。

测试覆盖快照时序、示例结果、递归与闭包、别名与循环引用、输入、语法与运行时错误、事件与输出上限、执行超时和 HTTP 访问校验。
